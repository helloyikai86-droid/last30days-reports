## 2. [e2e](https://github.com/tester-army/e2e)
- **24h Star 增量/替代指标**：+1,430（GitHub Trending stars today）
- **总 Star**：4,748
- **语言/技术栈**：TypeScript / Playwright / Mobile Agent / Agentic QA
- **标签**：AI/Agent / 企业AI / 开发工具 / 重点
- **通俗说明**：Agent 负责理解页面和执行语义动作，传统 locator/assertion 负责确定性验证；已经被断言证明正确的 Agent 动作还能在后续无模型 Replay。
- **目标用户**：Web/App SaaS 团队、QA、CI/CD、移动应用团队，以及希望减少 E2E 脆弱脚本维护的中小研发团队。
- **核心问题**：传统 Playwright/Cypress 很稳定，但 UI 小改就可能让 locator 失效；纯 Browser Agent 又灵活但昂贵、不够可重复。
- **过去做法**：纯 Playwright/Cypress/Appium；或者完全交给浏览器/视觉 Agent，每次测试重新理解页面。
- **它是什么**：Agentic E2E 测试框架，把语义探索与确定性验证结合，并把验证通过的 Agent 动作固化成可重放步骤。
- **工作机制**：测试中写自然语言动作；Agent 首次寻找并操作目标，后续 locator/assertion 验证结果；一旦该动作被后续 assertion 验证，就记录轨迹，下次应用未变化时直接 Replay，不再调用模型。
- **技术/架构**：TypeScript SDK/runner + Playwright Web + mobile agent/device + assertions/locators + replay cache + GitHub reporter + 可选 hosted browser/emulator。
- **近期爆火/加速原因**：10月5日日报为 +344，今天升到 +1,430，约 4.2 倍，是非常明显的老项目突然加速。
- **核心差异化**：不是让 AI 取代测试，而是只把 AI 放在最擅长的“语义寻找”环节；确定性结果仍交给 assertion，成本再由 Replay 降下来。
- **商业化/延伸方向**：Agentic QA SaaS、PR 自动回归、移动测试云、生产巡检、企业私有部署，可按并发、测试时长或项目收费。
- **中国市场机会**：国内 Web、H5、会员/支付、运营后台、游戏活动页和 App 都有大量回归测试场景；可接国产模型和国内真机云。
- **可借鉴场景**：注册/登录/购买流程；会员升级；后台表单；移动 App 关键路径；每 PR 自动 QA；生产环境定时巡检。
- **风险**：项目仍在 1.0 前；支付/删除等高风险操作必须使用隔离测试账号和环境；Replay 失效策略要严格验证。
- **启发**：AI 最合适的位置往往不是替代确定性软件，而是补上传统自动化最脆弱的语义理解部分。
- **明确判断**：★★★★★+。今天商业结构最漂亮的 B2B 项目，优先级最高。

- **语言/技术栈**：C++ / Executable Relinking / Shader Recompiler / SPIR-V
- **标签**：开发工具 / 新项目 / 重点
- **通俗说明**：尝试把 PS5 可执行内容自动重链接为 Linux/Windows 原生程序的兼容/移植工具，不是传统完整模拟器。
- **目标用户**：游戏兼容性研究、游戏保存/移植研究者、图形/系统程序员和技术内容创作者。
- **核心问题**：主机游戏的二进制格式、系统 PRX、着色器和图形调用与 PC 不同；传统兼容通常依赖完整模拟器或逐游戏手工移植。
- **过去做法**：模拟器、手工逆向/移植、运行时兼容层，通常需要模拟大量硬件/系统行为。
- **它是什么**：自动 executable porting 项目：Relinker 将 executable 转成目标系统原生格式，并提供系统 PRX 兼容实现；Shader Recompiler 将主机 Shader 转为 SPIR-V。
- **工作机制**：分析并重链接可执行文件，把系统库调用映射到兼容实现；图形 Shader 转成 SPIR-V，目标是在 Linux/Windows 原生进程运行。
- **技术/架构**：C++20 Relinker + system PRX compatibility layer + shader recompiler → SPIR-V + Linux/Windows native executable。
- **近期爆火/加速原因**：今天 +994，总 Star 仅 4,935；“不是模拟器，而是自动移植”这个叙事具有很强技术传播力。
- **核心差异化**：核心不是模拟整个主机，而是尽量把程序转换成目标平台原生可执行形式，理论上降低部分运行时模拟开销。
- **商业化/延伸方向**：短期更适合开发工具、兼容研究、游戏保存和技术内容；长期可延伸为跨平台移植辅助和 Shader/图形工具。
- **中国市场机会**：国内 PC/主机技术社区、游戏工作室移植研究、老游戏保存和开发者内容有明显选题价值；正式商业移植仍需版权授权。
- **可借鉴场景**：主机兼容研究；游戏保存；Shader/图形研究；移植技术演示；开发者教育。
- **风险**：兼容性仍早期；必须严格遵守游戏版权、EULA、DRM/反作弊边界；合法来源和授权是前提。
- **启发**：游戏工具不只存在“模拟器”一条路线，二进制移植、系统兼容层和 Shader 翻译本身也能成为工具品类。
- **明确判断**：★★★★☆+。技术选题价值很高，商业化边界需克制。
