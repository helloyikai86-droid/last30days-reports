## 1. laya

**通俗说明**：大量 Agent 子任务其实只是“从几个选项里选一个”“判断真/假”“打一个分数”。Laya 不生成一段文字再解析，而是单次 forward pass 直接返回候选概率。

**目标用户**：Agent 开发者、客服/审核/风控/路由团队。**核心问题与旧方案**：过去通常用规则、传统分类器，或调用昂贵 LLM 生成文本后再解析，延迟与 token 成本都偏高。

**为什么爆火**：9 月 18 日才创建，9 月 21 日日增已达 +2,194，属于真正的新项目爆发。**差异化**：非自回归、typed schema、概率可校准。

**商业化/中国机会**：做 Agent router、客服意图分类、广告/内容审核、审批判断、GUI 动作选择。中国企业大量高频工作流很适合把“简单判断”从大模型下沉到低成本决策层。

**风险**：适合封闭候选集，不适合开放式复杂推理；训练数据与概率校准决定效果。**判断：★★★★★+**。这可能是 Agent 成本结构变化的重要信号。

## 2. jev-ultrafast

把浏览器 Agent 的 CLICK、TYPE_TEXT、SELECT 等动作和元素建立动态索引，让快速决策模型选择动作，只有需要输入文字时才调用生成模型。它直接攻击 Browser Agent 最昂贵的“每一步都让大模型重新看页面并思考”问题。

**商业机会**：低成本网页自动化、客服后台、订单处理、广告投放后台、自动化测试。与真实登录态 BrowserSkill 组合尤其值得研究。**风险**：网页变化、权限、误操作和账号风控仍需要动作确认、回放与审计。**判断：★★★★★**。

## 3. laya-mlx

Laya 的 Apple Silicon 本地运行时，把 typed decisions 放到 Mac 本地毫秒级执行。商业上更像基础设施：本地 Agent 路由、隐私敏感邮件/文档分类、桌面自动化。它说明热门模型出现后，本地运行时、量化、平台适配本身就能快速形成产品机会。**判断：★★★★☆**。

## 4. security-audit-skill

Cloudflare 把安全审计拆成侦察、候选发现、证据、独立 reviewer 证伪和机器可读 findings。它解决的不是“模型会不会找漏洞”，而是“结论是否能被复核”。

**商业机会**：企业 Agent 审计控制层，并可迁移到合同、财务、广告素材、客服质检等高风险流程。**风险**：不能替代专业责任主体，大范围审计 token 成本仍高。**判断：★★★★★**。

## 5. nimble

Bespoke Labs 的开源 typed-decision 模型/训练路线，用本地模型做 choice/boolean 等结构化判断。机会在中文客服、审核、工单路由、风险判断的垂直小模型。真正壁垒不是 prompt，而是业务决策数据。项目仍早期，许可证与生产成熟度需单独核验。**判断：★★★★☆**。

## 6. trycua/cua

Computer Use 不只需要模型，还需要桌面环境、驱动、隔离、benchmark 和数据生成。CUA 在做这层“卖铲子”基础设施。

**商业机会**：桌面 Agent 云、企业私有执行池、软件测试、训练数据生成。中国大量 ERP、财务软件和桌面工具缺 API，需求真实；但基础设施较重。**判断：★★★★☆**。

## 7. json-render

Generative UI：模型输出受组件目录约束的 JSON，再渲染成表单、卡片、图表和操作界面。相比固定聊天框更适合复杂业务，又比让模型随便生成 React 安全。

**商业机会**：AI 动态审批、投研报告、客服工作台、运营后台、数据分析。**启发**：Agent 产品的下一层壁垒可能是人机协作 UI，而不是聊天能力。**判断：★★★★★**。

## 8. typesafe-ai/skills

把 typed-decision 能力直接包装成 Agent Skill，说明 System 1 决策层已经从模型层向 Agent 分发层扩散。商业上适合行业 Skill、企业私有 Skill Registry，但 Skill 文本本身复制门槛低，真正价值仍在数据、工具接入与验收规则。**判断：★★★★☆**。

## 9. BuilderIO/agent-native

核心思想是 **action once**：一个业务动作同时供 UI、Agent、HTTP、MCP、A2A、CLI 调用，并共享数据、状态与权限。Agent 不需要模拟点击 UI，而是和 UI 使用同一业务层。

**商业机会**：把传统 SaaS 改造成 Agent+UI 双入口，尤其适合 CRM、客服、邮件、日历、投研和运营后台。**判断：★★★★★**。

## 10. jianying-headless

把结构化剪辑计划变成剪映专业版原生草稿，可继续人工编辑，并可调用本机引擎导出 MP4。它连接了“AI 生成脚本/素材”和“最终人工后期交付”之间最费人的一段。

**目标用户**：短视频、手游买量、漫剧、电商内容团队。**商业机会**：模板化批量视频、广告 A/B、字幕/配音/轨道自动化。**中国机会非常直接**：不重做编辑器，而是进入团队已经在使用的剪映工作流。

**风险**：仅支持特定 macOS/剪映版本；原创部分商业使用需作者书面授权，剪映集成与素材许可也需独立确认。**判断：★★★★★+**。

# 今日最值得研究的 3 个机会

1. **System 1 决策层（Laya / Jev-ultrafast / Nimble）**：把 Agent 大量高频判断从昂贵生成模型下沉为毫秒级概率决策，直接改善成本、延迟和稳定性。
2. **Jianying Headless：可编程剪映后期**：对短视频、手游买量和漫剧团队最接近现实 ROI；应重点研究“脚本/素材 → 剪映草稿 → 人工兜底 → 批量导出”。
3. **Agent-Native + json-render：Agent 与 UI 融合**：企业 AI 不会长期停留在聊天框，动态 UI、共享 action、权限和状态将成为生产级 Agent 应用的重要产品层。
