## 1. [WordCraft](https://github.com/storytold/wordcraft)

**日增Star或替代指标：**+2,107（GitDiscover 10月11日滚动日增）　**总Star：**5,909　**语言/技术：**Rust / DOCX / WebAssembly / MCP / CLI

**通俗说明：**一个由Rust实现、围绕Word工作流设计的可编辑文档程序，支持样式、表格、修订、引用、邮件合并和DOCX读写，并将操作开放给CLI/MCP。它不是单纯把大模型回答导出成PDF。

**目标用户：**企业文书团队、投标/售前、法务运营、知识工作者，以及需要批量生成可编辑报告的AI工作流开发者。

**核心问题：**模型能写合同或报告内容，但需要准确保留标题样式、表格、页眉页脚、修订痕迹和可编辑DOCX时容易出现版式破坏；人工往往要重新排版。

**过去做法：**模板邮件合并、python-docx、Word COM/宏、人工复制粘贴，或让模型生成HTML再导入Office；复杂修订、引用和分页的一致性仍难保证。

**它是什么：**把专业文字处理器当成可编程文档引擎：既提供GUI，也把操作动作以命令接口暴露给AI Agent。

**工作机制：**Agent先选模板/创建文档，再通过命令修改段落样式、表格、修订记录和引用，使用DOCX导入导出；业务系统可对最终文件做版式与数据校验。

**技术架构：**Rust文档模型/排版和DOCX读写 + 跨平台GUI + WebAssembly + CLI/JSON控制通道/MCP；仓库自称支持多系统及网页端。

**近期爆火/加速原因：**10月10日报中它约1,857 Star、当时采用创建以来平均增长；10月11日GitDiscover记录滚动日增约+2,107，当前总Star达到5,909，显示短期关注度明显提高。不同指标不能直接视为同口径加速度。

**核心差异化：**输出是真正可二次编辑、可逐项修订和可用于企业交付的结构化文件；比“生成一页漂亮图片”更适合严肃工作。

**商业化/延伸方向：**行业合同/投标文书SaaS、企业报告批量生产、DOCX审校与格式质检、可审计的AI文档自动化API；适合按模板/席位/处理量收费。

**中国市场机会：**中文合同、投标文件、企业销售方案、培训资料和政府公文有巨大格式规范需求；可结合国产办公软件的兼容性测试和行业模板。

**可借鉴场景：**把CRM客户数据填入标准合同；按销售表生成可编辑月报；批量修改活动规则与会员说明；对修订前后逐项比较。

**风险：**仓库年轻，作者支持清单不等于工业级兼容；复杂中文字体、分页、批注和企业WPS/Word互开必须实测；商业使用需处理文档私密性。

**启发：**AI生成文字已经不稀缺，可校核、可修订、可交付的专业文件和工作流才是下一层价值。

**明确判断：**★★★★★。先选一类有固定模板、修改频繁的企业文件做垂直服务；不要从替代完整Office开始。
