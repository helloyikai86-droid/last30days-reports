## 2. WeKnora
- GitHub: https://github.com/Tencent/WeKnora
- 指标：+5,242 / 27,926 Star；Go
- 说明：腾讯开源知识平台，把文档变成 RAG、推理 Agent 与自维护 Wiki。
- 用户：企业知识库、客服/售前、研究团队、内部 AI 平台。
- 问题/旧方案：传统知识库检索弱，向量库+RAG 拼装维护成本高。
- 爆火：老项目突然加速；企业知识 Agent 仍是最明确的 AI 落地入口之一。

- 商业机会：行业私有知识库、售前/客服、研发文档 Agent、金融研究库。
- 中国机会：围绕中文资料、权限、本地部署和行业数据源交付。
- 风险：权限、引用、知识过期、通用知识库竞争。
- 判断：★★★★★。应做垂直行业而非再造通用知识库。

## 3. ArcBox
- GitHub: https://github.com/arcboxlabs/arcbox
- 指标：+2,501 / 6,186 Star；Rust
- 说明：给 AI Agent 提供独立内核、文件系统和网络的隔离机器，目标启动时间 <100ms。
- 用户：Agent 平台、Coding Agent、Computer-use 团队。
- 问题/旧方案：Docker 隔离不总够，传统 VM 启动慢；过去用 Docker/K8s/Firecracker/自建 VM。
- 爆火：总 Star 仅 6k 但单日 +2,501，Agent sandbox 需求快速上升。
- 差异化：真实隔离机器+本地优先+OCI 兼容。
- 商业机会：Sandbox API、企业私有 Runner、按秒计费执行环境、Coding Agent 基础设施。
- 中国机会：内网 Agent Runner、浏览器/桌面执行沙箱、代码数据隔离。
- 风险：虚拟化安全、逃逸、资源调度；基础设施竞争重。
- 判断：★★★★★+。今天最值得研究的新基础设施机会。

# 今日最值得研究的 3 个机会

1. **ArcBox：Agent Sandbox / 私有 Runner** — Agent 越能执行代码、浏览器和系统操作，越需要独立内核、文件系统、网络与审计权限。
2. **WeKnora：从 RAG 升级为自维护知识 + 推理 Agent** — +5,242 的突然加速说明企业知识 Agent 仍是明确入口；真正壁垒是行业数据、权限、引用与流程。
3. **Univer：Office Harness for AI Agents** — 增速不是最高，但商业落地极强，能直接进入报表、财务、OA、经营分析等高频流程。
