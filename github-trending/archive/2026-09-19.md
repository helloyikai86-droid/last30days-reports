## 1. hypit — 今天最值得新增研究
**通俗说明：** 不是普通文生视频，而是让 Agent 把一个爆款视频拆成可编译的 SVML：人脸、文案、B-roll、字幕、动效都能程序化替换，一条命令可以批量生产大量变体。

**用户/痛点：** 短视频团队、广告投放、跨境营销。过去复刻爆款要人工拆镜头、剪辑、找素材、逐条做 A/B，边际成本很高。

**机制/差异：** 参考视频或文字需求 → Agent 写 SVML → compiler 转 FFmpeg + HTML/CSS 动画 → Chromium 渲染。关键差异是把视频结构“代码化”，生成模型只是可选组件。

**为什么热：** 9/12 才首次进入 GitTrend，7 天约 +9.6k，平均约 +1.4k/天；9/18 仍有代码更新。

**商业机会：中国非常高。** 接国内视频模型、抖音/视频号规格、剪映素材链，可做广告素材工厂、商品视频本地化、漫剧/短剧二创、批量 Hook 测试。

**风险：** 版权/肖像权、平台重复内容检测、渲染成本、复杂审美仍需人工把关。

**判断：★★★★★+。** 对 AIGC 视频和买量团队，比再做一个“AI 剪辑器”更值得研究。

## 2. reef — Agent 持续学习基础设施
**通俗说明：** Agent 上线后把真实交互和反馈沉淀下来，自动形成训练/改 Harness 的候选版本，评估通过后再上线。

**用户/痛点：** 企业 Agent、客服、销售、研发 Agent。过去通常人工收集失败案例、定期改 prompt 或离线训练，反馈闭环很慢。

**机制：** Serve → Observe → Grow → Commit；既能更新模型权重，也能演化 prompt/rules/harness；支持 OpenAI-compatible API 和版本化 artifact。

**为什么热：** 最佳单日约 +800；近 7 天约 +2.6k。市场开始从“Agent 能执行”转向“Agent 如何越用越好”。

**商业机会：** 企业私有 AgentOps、客服自学习、销售话术优化、质检反馈闭环。真正可卖的是“反馈→评测→灰度→回滚”平台，不是无约束自我修改。

**风险：** 错误反馈导致漂移；必须有离线评测、版本控制、灰度、回滚和数据合规。

**判断：★★★★★+。** 企业 AI 基础设施里非常值得长期跟踪。

## 3. BrowserSkill — 真实登录态的 AI RPA
BrowserSkill 让 Codex/Claude Code 等通过 CLI + 本地 daemon + 浏览器扩展控制真实 Chrome/Edge，并复用现有 Cookie/登录态。近 7 天约 +3.3k，最佳单日约 +1.3k。商业机会是广告后台、CMS、订单、客服等没有完整 API 的真实业务流程。最大风险也是权限：必须做动作确认、审计日志、账号风控和人工接管。**判断：★★★★★。**

## 4. Orca — 多 Agent 的开发环境
Orca 给 Codex、Claude Code、OpenCode 等各自独立 git worktree，并提供桌面、移动、VPS/SSH 管理。30 天约 +22.8k，平均约 760/天。它证明 Coding Agent 的下一层产品不是更多聊天窗口，而是**并行 Agent 的隔离、监督、合并和远程控制**。商业上可做团队 Agent IDE/云端 Agent fleet，但通用赛道竞争激烈。**判断：★★★★★。**

## 5. OpenResearch — 从“建议”到“自动实验”
OpenResearch 用独立 worktree 并行跑研究方向，把日志、diff、结果、artifact 绑定到 Git lineage。近 7 天约 +4k。最值得迁移的不是科研，而是增长实验：素材 Hook、落地页 CRO、定价、活动策略。**判断：★★★★★。**

## 6. security-audit-skill — 可审计 Agent
连续项目，本期不重复深挖。核心仍是“执行 Agent → 独立 Reviewer → 程序 Validator”，并用 coverage ledger 和结构化 findings 证明覆盖和证据。它代表企业 Agent 从能力竞争进入**可信度/责任链竞争**。**判断：★★★★★。**

## 7. OpenCodeReview — 确定性 + LLM
阿里把文件覆盖、规则、定位等确定性工作交给程序，把跨文件语义判断交给 Agent。商业启发不是再做一个 Code Review，而是把“能程序化的不要让模型猜”迁移到合同、客服、财务、投放审核。**判断：★★★★★。**

## 8. ECC — Agent Harness 标准化
ECC 把 Skills、Memory、安全、工作流沉淀成跨 Codex/Claude Code/Cursor 的 Harness。机会在企业内部 Skill/规则治理、托管和可观测性，而不是继续堆通用 prompt。**判断：★★★★☆。**

## 9. i-have-adhd — 行为 Skill 的传播样本
它只解决一个高频痛点：让 Agent 少铺垫、先给动作。技术壁垒低，但证明“稳定行为模式”本身能形成安装需求。适合借鉴为中文岗位 Skill 包。**判断：★★★☆☆。**

## 10. Brigade — 自托管 AI 员工平台
Brigade 用隔离 Agent、共享长期记忆、消息总线和 1000+ connectors 组成 AI crew。机会是企微/飞书/钉钉 + 少量高频 SaaS 的垂直 AI 员工，而不是复制 1000 个连接器。**判断：★★★★☆。**

## 今日最值得研究的 3 个机会
1. **Hypit → 批量爆款视频/广告素材工厂**：最贴近可直接产生收入的 AIGC 营销场景。
2. **reef → 企业 Agent 持续学习/AgentOps**：把真实反馈变成可验证的版本改进。
3. **BrowserSkill + 可审计控制层 → 垂直 AI RPA**：进入真实登录后台执行，同时保留权限、人工确认和审计。

## 今日一句话
Agent 产品的竞争正在从“模型会不会做”转向四个工程层：**能进入真实系统、能并行执行、能被独立验证、能从反馈持续改进**。
