## 1. OpenStock
GitHub: https://github.com/Open-Dev-Society/OpenStock

- 指标：+843 today；总 Star 17,599；TypeScript / Next.js / React / MongoDB / Finnhub / TradingView。
- 通俗说明：开源股票市场终端，把行情、提醒、公司信息、新闻和图表做成完整产品。
- 目标用户：个人投资者、学生、独立研究员、小型投研团队。
- 核心问题/旧方案：专业终端价格高，小团队通常拼接 TradingView、行情 API、Excel/Notion；维护和产品体验割裂。
- 爆火原因：直接对标高价金融终端，价值主张清晰，金融信息产品本身有明确付费参照物。
- 差异化：不是量化框架，而是完整的终端用户产品壳，可自托管、二次开发门槛低。
- 商业化/中国机会：不要正面替代 Wind/同花顺，而是在其 API/Excel/PDF 之上做 AI 公司研究、事件监控、信用风险、组合预警和内部知识库，按席位/数据源收费。
- 风险：行情授权、金融合规、数据延迟、AI 幻觉。
- 判断：★★★★★。中国小型投研团队 AI 工作台值得重点验证。

## 3. agent-native
GitHub: https://github.com/BuilderIO/agent-native

- 指标：+607 today；本次 GitHub API 核验总 Star 5,887；TypeScript/React/PostgreSQL。
- 通俗说明：同一个业务 action 同时给 Agent、UI、HTTP、MCP、A2A、CLI 使用。
- 目标用户：AI SaaS、企业 AI 团队、垂直 Agent 创业者。
- 核心问题/旧方案：传统“聊天框 + 单独业务前端”会重复建设权限、校验和状态；让 Agent 模拟点 UI 又很脆弱。

- 爆火原因：Agent 产品正在从聊天转向可操作工作台。
- 差异化：核心不是生成 UI，而是 Agent 与 UI 共用业务动作和权限模型。
- 商业化/中国机会：企微运营、投研、采购、客服、内容生产等“Agent + 工作台”；也可卖行业 action pack。
- 风险：框架新；商业使用前需核验仓库许可；action 权限设计错误会放大风险。
- 判断：★★★★★+。今天最值得做产品研究的项目之一。

## 10. json-render
GitHub: https://github.com/vercel-labs/json-render

- 指标：9月21日可验证快照 +787；约17.8k Star；TypeScript/React。当前 GitHub Trending 页面未显示，因此未冒充 9月22日实时日增。

- 商业化/中国机会：动态审批、投研报告、客服工作台、运营后台、AI 表单和分析界面。
- 风险：复杂交互仍依赖组件库；schema 设计决定能力上限。
- 判断：★★★★★。与 agent-native 组合看，代表 Agent-native SaaS 的新交互层。

# 今日最值得研究的 3 个机会

### 1. Agent-native SaaS：agent-native + json-render
一个解决 Agent/UI 共用 action，一个解决受约束动态 UI。组合后可做“Agent 能执行、人能看见/编辑/审批”的企业软件，比单纯聊天机器人更接近真实付费产品。

### 2. 中国小型投研团队 AI 工作台：OpenStock + financial-services
不要替代 Wind/同花顺，而是把现有 API/Excel/PDF、公告、研报和持仓接入 Agent 工作流，卖研究效率、事件监控、信用风险、知识沉淀和团队协作。

### 3. AI 视频二创流水线：AutoClip
已有长视频 -> 高光识别 -> 字幕/标题/CTA -> 剪映草稿/人工复核 -> 多平台发布。相比纯生成视频，成本和质量更可控，商业 ROI 更直接。
