- **中国市场机会**：国产模型适配、私有化、记忆来源/置信度/过期/删除/权限/审计。

- **风险**：错误记忆会长期污染决策；隐私、遗忘和来源可信度必须治理。
- **启发**：Agent 竞争会从上下文长度转向长期学习质量。
- **明确判断**：★★★★★+。今天热度第一，也是最成熟的 Agent 基础设施机会之一。
