### 1. [PhotoCraft](https://github.com/storytold/photocraft)

**滚动日增 Star 代理：** +4,842（GitDiscover Hot 2026-10-13；非严格24小时）  
**总 Star：** 58,005（10/14 独立快照）  
**语言/技术栈：** Rust / wgpu / PSD / CLI / MCP  
**标签：** AIGC、增长/内容、开发工具、重点、新项目  
**许可证：** Apache-2.0（README 另标 MIT OR Apache-2.0）

**通俗说明：** 在 Rust 中重建 Photoshop 式图层编辑器，支持 PSD、蒙版、文字和调整层，可由 AI Agent 调用编辑命令。

**目标用户：** 广告素材设计师、手游买量团队、设计外包公司、需要高频改图的电商商家。

**核心问题：** AI 可以生图，但无法保证只修改现有 PSD 的售价或按钮而不破坏其他图层。

**旧方案：** Photoshop 人工打开模板改字、Photopea 批量动作、重新生成整张图后再人工修正。

**项目定位：** 本地优先分层图像编辑器，官方标注 early alpha，不应当作完整 Photoshop 替代品。

**工作机制：** 统一的编辑命令可通过 GUI、CLI、JSON 控制通道、MCP 执行，让 Agent 精确选择图层和属性。

**技术架构：** Rust 文档内核 + wgpu GPU 合成 + PSD 格式处理 + CLI/MCP Agent 控制。

**近期爆火/加速原因：** GitDiscover 10/13 滚动热榜 +4,842；创作软件系列带来流量联动，分层可编辑能力与内容生产需求高度匹配，因果仍是推测。

**差异化：** 编辑已有结构化资产，不必让模型每次重新生成整张图；强调可回溯、可修改的层级。

**商业化与延伸方向：** 品牌素材改版 SaaS、广告投放创意批量生产、PSD 模板 API 和企业内网设计流程自动化。

**中国市场机会：** 手游推广与会员销售站需要不同渠道、售价、比例的海报，可从原创模板的变量替换与合规校验切入。

**可借鉴场景：** 选 20 份真实中文 PSD 模板，批量生成 3 种价格×4 个尺寸，人工抽查字体/徽标/图层是否保持一致。

**风险：** PSD 兼容、中文字库、早期软件崩溃、字体版权及错价广告风险；需独立测试可靠性。

**启发：** 小团队最有价值的是建立可编辑素材工厂，而不是再做通用生图 App。

**明确判断：** 优先级 A：建议作为广告素材工业化的第一项 PoC。
