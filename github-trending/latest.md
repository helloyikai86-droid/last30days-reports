**通俗说明：** 让AI Agent读取真实桌面应用的辅助功能树，并用稳定元素引用执行点击、输入和检查结果，避免完全依赖截图坐标。

**目标用户：** 企业流程自动化服务商、测试团队、研发Agent作者、需要跨应用操作的业务平台。

**要解决的问题：** 传统视觉代理遇到分辨率变化、窗口遮挡和界面重排容易点击错目标，生产环境难复现且难排查。

**具体是什么：** Vercel Labs开源的桌面操作底层工具，并非直接交付完整的AI员工或自动化SaaS。

**工作机制：** CLI为窗口创建辅助功能快照、分配元素ref；Agent根据结构选择控件，执行后重新抓取快照进行核验；保留引用的可靠性优先于猜像素。

**技术架构：** Rust原生核心、Windows/macOS/Linux平台辅助功能后端、命令行和C接口；可嵌入现有Agent框架。

**近期爆火/加速背景：** 11月2日增速榜观察到+1,872的当日代理增长，稳定跨应用控制是Agent从聊天走向执行的关键瓶颈；不能据此证明某次发布是唯一原因。

**核心差异化：** 操作目标是OS语义元素而非屏幕像素，支持跨系统、可复查的行动链；若应用不暴露辅助功能树仍需其他手段。

**商业化及延伸方向：** 做企业内网RPA替代底座、自动化验收服务、可控桌面Agent网关；按流程实施、维护和任务量收费。

**中国市场机会：** 国内CRM后台、订单工单、营销素材上传、财务对账界面可用授权测试环境探索，避免脚本使用真实支付权限。

**启发：** Agent可靠性首先是定位与验证能力，而不是更复杂的提示词；底层稳定接口可被多个垂直业务复用。
